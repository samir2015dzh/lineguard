# LineGuard 0.3.0-preview.4 — 开发预览（危险、未验收、未签名）

> **不是可用 VPN，不要在日常电脑上运行危险命令。** Connect 仍返回 Unsupported，没有任何“已保护”状态。exe 未签名。

## 本版变化
- **只需打开 `lineguard.exe`**：界面会自动连接已安装的系统服务或本机后台；都没有时显示「启动本机后台」，点一下即在后台静默启动 `lineguard-service.exe`（当前用户、无窗口、不安装服务、不改网络），关闭界面时一起退出。
- **界面配色修复**：在浅色 Windows 主题下标题发黑、按钮发白、分隔线刺眼的问题已修复（强制深色主题并显式设置所有控件颜色）；新增主按钮样式，侧栏使用应用图标。
- 侧栏显示真实版本号。

## 怎么试
1. 解压，4 个 exe 保持在同一文件夹。
2. 双击 `lineguard.exe` → 点「启动本机后台」。
3. 在「离线线路」页导入 `examples/offline.example.json` 体验格式校验。

`lineguardctl.exe` / `lineguard-rescue.exe` 是命令行工具，仅管理员实验与紧急恢复使用。

## 仍未验证
v3 窄放行的真实联网、开机冷启动阻断、服务/BFE 崩溃、旁路/泄露抓包。详见包内 `HANDOFF.md`。
