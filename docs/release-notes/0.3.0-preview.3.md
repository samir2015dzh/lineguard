# LineGuard 0.3.0-preview.3 — 开发预览（危险、未验收、未签名）

> **不是可用 VPN，不要在日常电脑上运行。** Connect 仍返回 Unsupported，没有任何“已保护”状态。
> 实验命令会**有意切断本机全部 IP 联网**，只能在带独立控制台和快照的隔离 Windows 虚拟机里使用。exe 未签名。

## 这个预览包含什么
- 原生 egui 界面 + 受限命名管道 + Rust 后台服务，离线配置导入（DPAPI 加密保存）、脱敏诊断。
- M2 全阻断（6 持久 + 6 开机 WFP 规则）及不依赖服务的独立救援 `lineguard-rescue`。
- M3：独占 TUN 隔离、写前网络 journal、独立应急阻断与恢复。
- 新增 v3 窄许可（ALE 身份门 ∩ 包层例外）：计划、原生事务、逐字段回读、单事务撤销；管理员实验命令 `lineguardctl tun open --confirm OPEN-NARROW-DATA-PATH`。

## 已有的实测证据（GitHub 托管的一次性 Windows VM，CI）
- console IPC：状态、导入、诊断不泄露密码、Connect 拒绝。
- 全阻断安装后逐字段回读精确，**出站 TCP 实际被阻断**；独立救援撤销后无残留、直连恢复。

## 尚未验证（不要依赖）
- v3 窄放行的真实安装与隧道联网（需固定版本 mihomo 核心与真实节点）。
- 开机冷启动阻断、服务/BFE 崩溃、旁路/泄露抓包、物理网卡与 TUN 恢复。
- 与其他 VPN / 已有 Wintun 共存（明确不支持）。
